# Combat Achievements Tracker

Type an OSRS username and see which Combat Achievement tasks that account has done, its points, and how far it is from the next mastery tier. Completion comes from WikiSync, the same data RuneLite's WikiSync plugin publishes to the wiki.

The lookup only works for accounts that have WikiSync enabled in RuneLite and have opened their Combat Achievements interface in-game at least once since.

## Files

| Path | What it is |
|---|---|
| `index.html`, `style.css`, `app.js` | The web tracker (what GitHub Pages serves). |
| `tasks.json` | All 646 tasks: `task_id`, boss, name, description, type, tier, points. Generated by the scraper. |
| `worker/wikisync-proxy-worker.js` | Copy of the Cloudflare Worker that relays WikiSync requests. Live at `https://osrs-ca-tracker.julianj0793.workers.dev`. |
| `desktop/combat_tracker.py` | The original Tkinter app (manual check-off, SQLite `progress.db`, mastery bar, WikiSync sync). Archived; still runs. |
| `desktop/scrape_ca_tasks.py` | Pulls the task table from the OSRS Wiki into `tasks.json`. |

## How the lookup works

```
Browser (this page) ──► Cloudflare Worker ──► sync.runescape.wiki/runelite/player/<name>/STANDARD
                         adds CORS header        returns combat_achievements: [task ids]
        ◄── task ids ──┘
tasks.json task_id  ──► matched → completed, points summed → mastery tier
```

`sync.runescape.wiki` refuses requests from other websites' pages (403, no CORS header), so the page can't call it directly. The worker calls it server-side and passes the answer back. The worker holds no secrets, so its URL being public in `app.js` is fine.

## Mastery thresholds

Cumulative points from tasks of any tier: Easy 41, Medium 161, Hard 419, Elite 1,075, Master 1,945. Grandmaster has no points threshold; it needs every task done. These are set in `TIER_THRESHOLDS` in both `app.js` and `desktop/combat_tracker.py`. If Jagex changes them, update both.

## When new tasks are added to the game

```
cd ca-tracker/desktop
pip install requests beautifulsoup4
python scrape_ca_tasks.py
copy tasks.json ..\tasks.json        (Windows)   or   cp tasks.json ../tasks.json
```

Then commit `ca-tracker/tasks.json`. The scraper warns if it finds fewer than 600 tasks.

## Running the desktop app

```
cd ca-tracker/desktop
pip install requests
copy ..\tasks.json .                 (or cp ../tasks.json .)
python combat_tracker.py
```

Progress is saved to `progress.db` next to the script. It's a plain SQLite file, so you can query it from DB Browser for SQLite, R (`RSQLite`) or pandas with the app closed. Don't commit it.
